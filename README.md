# 本音(ほんね)

本のバーコード音楽。読む本の裏のバーコード(ISBN)にスマホをかざすと、その本だけの静かな音楽が、止めるまで流れ続けます。カフェで本を読むときのBGMに。

- 同じ本なら、いつ誰が鳴らしても同じ音楽になります。
- 本のジャンルでは変えません。その本にたまたま付いた番号だけで決まる、偶然の音楽です。
- 生成AIは使っていません。数字を5音の音階と和音に置き換えています。

公開ページ: https://takashi-okazawa-jp.github.io/honne/

バーコードの読み取りに [ZXing](https://github.com/zxing-js/library)(Apache License 2.0)を使っています。題名と表紙は openBD と Google Books の公開データから取得します。
